# Threat Hunting

Cyber-Sentinel-Forge threat hunting is hypothesis-driven, evidence-based, and explicitly connected to detection engineering.

## Standard

Every hunt must define:

- hypothesis and threat context;
- MITRE ATT&CK mapping;
- required telemetry;
- broad query logic;
- baseline/prevalence approach;
- pivot strategy;
- evidence collection;
- benign/suspicious/incident decision criteria;
- limitations and blind spots;
- Hunt → Detection feedback.
