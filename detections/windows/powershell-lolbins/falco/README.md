# Falco Applicability

Falco is registered as a first-class Cyber-Sentinel-Forge detection engine for **Linux runtime, syscall, container, Kubernetes, and cloud-native** use cases.

This specific pack is Windows process-creation focused, so a Falco rule is intentionally **N/A** rather than an artificial translation.

Future Linux/container detection packs will include Falco YAML rules where the observable is available to Falco.
